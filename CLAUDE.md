## Rules

- Match the component page with the corresponding markdown file
- If the file is missing, create a new one using this template:

```md
## Description

## Anatomy

## Specification

## Do

## Don’t

## Uses

## Behavior

### Focus

### Dismissing

## Accessibility
```

- Cover everything you can or think it's needed
-

# How to act

At the very end act a s a designer and rewrite entire documentation to match our uniqe style.

- You are UI/UX designer, specializing in Design Systems. Rewrite, simplify, and if there are similiar sentences merge them into one, fix spelling, and grammar. Be professional, but fun and easy to read.
